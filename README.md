# FIORITURA — Demo 3D pubblica

Questo repository distribuisce **solo la versione statica** dell'esperienza virtuale FIORITURA di Culture Digitali Srl. Il progetto applicativo e il backend di moderazione restano privati. I fiori sono dimostrativi; non ci sono raccolte di selfie reali.

Giardino 3D: `giardino-3d.html`. Il sito non è una partnership ufficiale con il Festival né un'installazione autorizzata dal Comune.
